Jumpedia is built around a few core concepts that define how data is organized and managed.

Understanding these concepts will help you understand how communities, users, lists, attributes, and tasks work together and will make working with commands way easier.

The easiest way to learn about the concepts is to follow the order in which they are represented in this documentation. 

Some concepts might be mentioned before they are fully explained yet, which is sometimes unavoidable. If something is unclear, it can always be skipped and read about later again. 

If something is still unclear, feel free to ask in Jumpedia's dedicated [help forum](https://discord.gg/xjP7FzNKsV).
