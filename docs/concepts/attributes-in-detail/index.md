An attribute defines a specific property a task of a specific list has.

Attributes can represent things like a task name, difficulty, category, completion date, or any other value a community wants to track.

Each attribute has a set of configuration options that define its behavior.

## Attribute Properties

Every attribute has:

- A name and optional aliases.
- A type defining what the attribute belongs to.
- A kind defining special behavior.
- Field configuration defining allowed values of tasks.
- A display position.
- An optional collection.
