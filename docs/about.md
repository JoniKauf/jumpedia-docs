## Who created Jumpedia and why?

Jumpedia was first created between 2022 and 2023 for a very specific use-case. It was a hardcoded bot for the Super Mario Odyssey Trickjumping community to store trickjumps, since the old bot of the community broke and didn't support all features we needed. Its code can still be found [here](https://github.com/JoniKauf/JumpediaOld). Be warned though: it was my first ever Python project and the code therefore aged very badly!

This worked well for a while, but then other communities asked whether the bot could be used for their community as well. It could not, since everything was hardcoded to work only for SMO trickjumping (which also made it a lot simpler of course). We then got the idea to transform Jumpedia into a general purpose, community and task managing Discord bot, usable by any community.

So, for over 2 years Joni worked on this new version called "Jumpedia 2.0". The name was kept since it sounds good and also reminds us of its humble origins. In February 2026 Jumpedia 2.0 finally released with slash commands and many more features. Trickjumps were now abstractly called "tasks" and the trickjumping community was not the only community anymore.

Then, after trying to add new features, some problems arised. The new slash commands were great and the code definitely better than in Jumpedia's first version, but it was still not very well structured. The code was simply rushed because it already took so long to finish Jumpedia 2.0 in the first place.

So the decision was made to clean up the code first before actually adding new features. This turned out to be basically a whole new rewrite of the code, but after around 6 months it was finally done. The whole architecture of the code now followed well established standards and everything was neat and organized. New features would now be a breeze to implement.

So as of writing this on August 10th 2026, Jumpedia 2.0's even newer version is officially done and will have been updated in the next few days.


## Use Of AI

This about page was completely written by hand from me, Joni (at least its first version, when I'm writing this). 

Because I'm very critical about the use of AI in many fields, I feel morally obligated to specify exactly how AI was used for Jumpedia.

Even though this page has never been seen by an AI, the rest of the documentation and Jumpedia's codebase used generative AI.

I don't really like writing documentation, since I'm really a programmer at heart. Writing documentation can also be incredibly tedious and I am not a native english speaker either, which makes writing clean documentation even harder. Writing the first version of these docs still took me over 25 hours with AI though. 

Why so long you might ask?

**Because AI was used as a tool!**

Most pages were first written by AI to create the basic structure and have the wording be clean. Then I always fixed a lot of things by hand, made them sound better, less AI like and often basically rewrote the entire page either way.

So, to be transparent, this is the disclaimer about the usage of AI; ChatGPT to be exact. Documentation is important, but not everyone is good at it or likes spending tens of hours to write it!

Also, ChatGPT was also used for helping to create Jumpedia's codebase, but as an assistant really. Most code was written by hand and ChatGPT helped more as a software architect and asking it questions of good design decisions.
