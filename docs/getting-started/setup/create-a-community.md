To create a new Jumpedia community, you need to request one on the official Jumpedia server.

1. Join the server with [this link](https://discord.gg/AagYZRqhWj).
2. Go to the [**`community-request`**](https://discord.gg/dtAgjHKZpy) forum channel.
3. Create a new forum post for your community request.
4. Follow the request template provided in the pinned message of the forum channel.
5. Fill out all required information about your community.

Once your request has been reviewed and approved, your community will be created and can be connected to your Discord server.

This process exists for 2 major reasons:
1. Since all data is stored on Jumpedia's internal database, we don't want spammers to waste storage.
2. The global community namespace needs to be moderated so nobody can squat on community names that they know other communities might want to use.
