---
title: Link To An Existing Community
description: Connect your Discord server to an existing Jumpedia community.
sidebar_position: 1
---

If your community already exists inside of Jumpedia and you want to connect it to another server, you can do this pretty easily.

To link your server, use the [server link](/commands/staff/server#server-link) command inside any channel of the server you want to link. You need to at least have a role with administrator permission in the server.

Once the server has been linked successfully, all members of the server will be able to access the community's lists, tasks, and other data. Only people with the required (/concepts/users/ranks#community-ranks) are allowed to actually change the community's data though.

If your desired community does not exist yet, continue to [Create A Community](/getting-started/setup/create-a-community).
