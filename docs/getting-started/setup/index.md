Before using Jumpedia, your server needs to be linked to a community.

A community in Jumpedia represents an actual existing community of people sharing the same interest. 

A single community can be connected to multiple Discord servers, allowing the same data to be accessed from different places. One server can only be connected to one community at a time though.

One can either connect to a server to an existing community or create a completely new community.
