Before using Jumpedia, your server needs to be linked to a community.

A community in Jumpedia represents an actual existing community of people sharing the same interest. 

A single community can be connected to multiple Discord servers, allowing the same data to be accessed from different places. One server can only be connected to one community at a time though.

## Invite the Discord bot

To proceed to one of the next steps, first the Discord bot needs to invited to the desired server with [this link](https://discord.com/oauth2/authorize?client_id=1467573198622036145&permissions=7336345509162049&integration_type=0&scope=bot).

Note:<br/>
Jumpedia currently doesn't currently need all permissions listed when inviting the bot, but it might need some of them in the future. Therefore it is recommended to invite the bot with all permissions listed as checked, so it works flawlessly in the future as well. If some important permissions are missing, the bot might not work at all!
