Welcome to Jumpedia!

This section explains the basics needed to start using Jumpedia. It introduces what Jumpedia is, how communities work, and how to connect or create a community.

## Overview

To start using Jumpedia, you generally follow these steps:

1. Understand what Jumpedia is and how it organizes data.
2. Join an existing community or create your own.
3. Configure your lists, attributes, and tasks.
4. Start managing your community using commands.

## Setup

Choose the setup method that matches your situation:

- **Link To An Existing Community**  
  Join a community that already exists in Jumpedia.

- **Create A Community**  
  Create a new Jumpedia community and configure it for your needs.

After completing setup, continue with the concepts section to understand how Jumpedia structures data, or explore the available commands.
