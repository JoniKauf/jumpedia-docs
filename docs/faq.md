## Source Code

**Q:** Where is the source code of Jumpedia?

**A:** Currently Jumpedia is closed sourced, but this will likely change in the future. 

Jumpedia's ecosystem benefits a lot from all communities being inside of one bot, as it makes all data global and all existing communities accessible by inviting a single bot. Therefore for now it is closed-source, at least until some amount of communities get established first. We want to prevent people from copying the bot and the whole community system therefore not really working anymore.

This obviously has some disadvantages as well, that's why we plan to release the source code at some point in the future. For example, currently no private communities are possible. This could become a feature though and if not, communities that are small and want to stay private can host the bot themselves in the future.
